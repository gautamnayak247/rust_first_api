# Employee API

This is a **dual-mode Rust project** that provides an Employee management API in two formats:
- **WebAssembly (WASM)** – Compile to JavaScript/Node.js for use in web browsers or Node.js environments
- **REST API Server** – Run as a native HTTP server using Axum framework

## Project Structure

```
src/lib.rs    - WASM-compatible functions (used by wasm-pack)
src/main.rs   - Axum REST API server (native Rust binary)
pkg/          - Generated WebAssembly artifacts (auto-generated by wasm-pack)
examples/     - Node.js example demonstrating WASM usage
```

## REST API Endpoints

### Health Check
- **GET /**
  - Returns: `"healthy!"`

### Employee Endpoints

- **POST /employees**
  - Description: Create a new employee.
  - Request Body:
    ```json
    {
      "id": 1,
      "name": "John Doe",
      "role": "Developer"
    }
    ```
  - Response:
    - Status: `201 Created`
    - Body:
      ```json
      {
        "id": 1,
        "name": "John Doe",
        "role": "Developer"
      }
      ```

- **PUT /employees**
  - Description: Update an existing employee.
  - Request Body: Same as POST.
  - Response:
    - Status: `200 OK`
    - Body: Same as POST.

- **GET /employees**
  - Description: Retrieve an example employee.
  - Response:
    - Status: `200 OK`
    - Body:
      ```json
      {
        "id": 1,
        "name": "Gautam",
        "role": "Permanent"
      }
      ```

## Running the Project

### Prerequisites

Install Rust from: https://www.rust-lang.org/tools/install

### Option 1: Run as REST API Server (Native Rust)

```bash
cargo run
```

Server starts at `http://127.0.0.1:3000`

### Option 2: Compile to WebAssembly (WASM)

Install wasm-pack:
```bash
cargo install wasm-pack
```

Build WASM package:
```bash
wasm-pack build --target bundler
```

Test with Node.js:
```bash
node examples/node_example.mjs
```

Or use in your JavaScript project:
```javascript
import { create_employee, get_employee, update_employee } from './pkg/employee_api.js';

const emp = get_employee();
console.log(emp);
```

## Dependencies

### Core Dependencies
- **Serde** – Serialization/deserialization library
- **Serde JSON** – JSON support

### Server (REST API)
- **Axum** – Web framework for building HTTP APIs
- **Tokio** – Asynchronous runtime for Rust

### WebAssembly
- **wasm-bindgen** – Enables Rust ↔ JavaScript interoperability
- **serde-wasm-bindgen** – Serializes Rust structs to/from JavaScript objects
- **js-sys** – Bindings for JavaScript APIs
